# Contributing to p-SWAMP

Contributions are welcome. How to set up, check a change, sign off your
commits (DCO) and open a pull request is on the documentation site:

**<https://p-swamp.github.io/p-SWAMP/project/contributing/>**

The same page is in this repository at
[`doc/project/contributing.md`](doc/project/contributing.md).

Contributors follow the
[LF Projects Code of Conduct](https://lfprojects.org/policies/code-of-conduct/).
